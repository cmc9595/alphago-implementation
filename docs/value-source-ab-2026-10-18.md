# 가치망 데이터 구성 비교 (2026-10-18)

목적: SL 정책 + 별도 가치망 + MCTS 구성을 유지하면서, 가치망 학습 자료 구성의 영향을 분리한다. 빠른 롤아웃이나 KataGo 교사 라벨을 추가하지 않는다.

## 두 실험의 공통 조건

- 초기 가중치: checkpoints/rl_6x96/final.pt. 각 실험에서 동일한 가중치 및 난수 시드로 새로 시작한다.
- 구조: 6블록·96채널, 정책 head 제거, 가치 head + 소유권 head. trunk까지 학습한다.
- SGD momentum 0.9, Nesterov, weight decay 0.0001, 학습률 0.02, 500스텝 워밍업 후 코사인 감소.
- 각 30,000회 optimizer 업데이트 × 유효 배치 256 = 7,680,000개 학습 표본 제시.
- 실제 계산 배치 64 × 기울기 누적 4회. 두 실험에서 동일하지만 BatchNorm 통계는 과거 배치 256 학습과 다르다. 따라서 과거 모델과의 차이 전체를 데이터 구성 효과로 해석하지 않는다.
- 소유권 손실 가중치 1.5 유지. 이번에는 소유권 유무·구조·중반 샘플 가중치를 함께 바꾸지 않는다.
- mixed 종료 후 generated 실행. GPU 학습은 하나씩만 실행한다.

## 다른 조건

- mixed: 기존 gen + RL archive + human 혼합, 학습 국면 수에 비례한 샘플링.
- generated: 별도 생성 gen 자료만 사용. 기존 기보 및 GNU Go 라벨 재사용.
- gen은 생성 스크립트상 최종 RL 모델을 사용하지만, 과거 파일에 생성 당시 모델 해시가 저장되어 있지 않다. 출처가 완벽하게 인증된 신규 데이터라고 표현하지 않는다.

## 실제 자료 점검

- gen: 247,697판, 742,999국면. 두 번 패스 종료 246,414판. 미종료 1,283판(약 0.52%). 길이 400 이상은 1,309판으로, 400수째 두 번 패스로 종료된 경우도 있어 미종료 수와 다르다.
- RL archive: 711,680판, 1,423,360국면. 두 번 패스 종료 707,297판. 미종료 4,383판(약 0.62%). 전부 judged 표시가 있다.
- human: 27,244판, 217,952국면. 1,696판은 덤/결과 경계 처리로 가치 라벨 0. 기존 방식대로 해당 국면의 가치 손실은 제외하고 소유권 손실은 사용한다.
- 라벨 일관성 비교가 목적이므로 이번 실험에서 미종료 판만 별도로 제거하지 않는다. 기존 GNU Go 라벨의 정확성이 보장된다는 뜻은 아니다.

## 공통 검증

기존 ValueData의 판 단위 3% 제외 자료를 유지하고, 그 안에서 판 단위로 selection/report 두 묶음으로 나눴다. 각 묶음에서 출처·수순 단계별 표본을 고정한다.

- selection: 실제 9,199국면. 매 2,000스텝 및 마지막에 동일 국면으로 검증한다.
- report: 실제 9,133국면. 두 실험 완료 후 SL 가치망, 기존 value_own, mixed, generated를 동일 국면에서 평가한다.
- 체크포인트 선정: selection의 gen/RL/human 각각의 MSE를 동일 가중 평균한다. generated 실험이라고 gen만으로 체크포인트를 고르지 않는다.
- 전체, 출처별, 수순 단계별, 출처별 중반 MSE·승패 정확도·보정 오차를 저장한다. 균형 표본의 전체 MSE는 예전 무작위 표본의 0.618과 직접 비교하지 않는다. 기준 모델도 이번 표본에서 다시 평가한다.
- 이 자료는 과거 모델 선정에 사용된 검증 자료를 재사용한다. report는 이번 실행의 체크포인트 선정에서는 제외하지만, 완전히 미사용인 최종 테스트는 아니다.
- RL 초기 모델은 과거 archive 게임 생성/강화학습에 관여했다. archive 제외는 이번 가치망 지도학습 업데이트에 대한 분리이며, 초기 모델까지 완전히 처음 보는 기보라는 보장은 없다. 별도 gen 결과를 특히 중시한다.
- MSE 감소만으로 기력 향상을 확정하지 않는다. 유망한 모델에 대해 동일 탐색 횟수 MCTS 대국 및 고정 사활 사례를 후속 검증한다. 현재 8765 모델은 자동 교체하지 않는다.

## 실행 및 진행률

프로젝트 폴더에서 실행:

```sh
.venv/bin/python scripts/value_source_ab.py --watch
```

재개 명령:

```sh
.venv/bin/python -u scripts/value_source_ab.py
```

중복 실행은 파일 잠금으로 차단한다. 각 100스텝마다 last.pt를 원자적으로 저장하고, 같은 설정으로 다시 실행하면 optimizer·난수 상태를 포함해 재개한다. 설정이나 데이터 파일 목록/크기/수정 시간이 바뀌면 재개를 거부한다.

결과 폴더: runs/experiments/value_source_ab_20261018/

- state.json: 현재 단계·진행률
- run.log: 표준 출력과 오류
- audit.json, manifest.json, evaluation_rows.npz: 자료 점검·설정·고정 평가 표본
- baseline_validation.json: 기준 모델의 이번 selection 성능
- report_results.json: 두 실험 종료 후 동일 report 표본의 최종 비교
- checkpoints/value_ab_mixed_20261018 및 checkpoints/value_ab_generated_20261018: 신규 가중치·학습 로그

## 메모리 제한

MPS 프로세스 메모리 비율 0.12, 실제 배치 64, 학습 순차 실행. CPU peak RSS 8GiB 초과 또는 macOS memory_pressure가 보고하는 여유 비율 10% 미만이면 실험을 오류 상태로 중단한다. 기존 앱이나 서버는 종료하지 않는다. 이 점검은 주기적이며 시스템 전체 OOM 방지를 보증하는 하드 한도는 아니다.

관련 자동 테스트: tests/test_value_source_ab.py의 판 단위 분리·평가 표본·모델 선정·라벨 마스킹·예상 시간 계산 6개 통과.

진행률 화면은 최근 10개 학습 기록의 평균 처리 속도로 각 실험의 남은 학습 시간, 순차 실행 대기 시간을 포함한 종료 시각, 전체 남은 학습 시간과 예상 총소요를 표시한다. 아직 시작하지 않은 generated는 mixed 속도로 추정한다고 명시한다. 검증/최종 평가 및 잠자기 시간은 추정에서 제외하며, 진행 기록이 120초 이상 갱신되지 않으면 종료 시각 표시를 보류한다. 이전 버전으로 실행 중인 --watch 화면은 Ctrl+C 후 같은 명령으로 재실행해야 적용된다. 학습 프로세스 재시작은 필요 없다.
