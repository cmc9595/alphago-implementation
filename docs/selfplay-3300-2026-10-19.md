# 3,300판 공유 모델 MCTS 자가대국 생성 (2026-10-19)

사용자 승인: 3,300판을 바로 생성하고 기존 Claude progress.py/progress_value.py 형태의 깔끔한 터미널 모니터를 만든다. 생성 후 학습은 아직 시작하지 않는다.

- 실행 이름: selfplay_cap_3300_20261019
- 모델: checkpoints/shared_supervised_6x96_20261018/best.pt (24,000스텝), 정책·가치 공유 trunk.
- seed20262019 + 판 번호. 예비32판의 seed20261019~20261050와 겹치지 않는다. 시작 설정 점검에서 첫 실행 seed가 겹침을 발견해 중단하고, 완료된 초기 판을 *_seed_overlap_stopped 폴더에 보존한 뒤 새 seed로 재시작했다. 보존한 판은 이3,300판에 합치지 않는다.
- 25%의 수는400회,75%는100회. 배치32. 400회만 학습 대상 train_mask=True.
- 원본32판과 독립된 새 폴더에3,300판을 생성한다. 이 실행 안에서는 판별seed가 유일하다. 이전32판을 학습 데이터에 자동 합치지 않는다.
- 나머지 수순/판정/메모리제한/재개/시간 측정 범위는 docs/selfplay-cap-pilot-2026-10-19.md 및 실행 manifest.json 참고.
- 기록: runs/experiments/selfplay_cap_3300_20261019/{state.json,game_*.npz,game_*.json,game_*.sgf,runner.log,summary.json}.
- 32판 실측17.2초/판 기준 예상15시간46분. 실제 ETA는 최근20판 속도로 갱신한다.

## 모니터

```sh
cd /Users/myungchulcheon/alphago-implementation
.venv/bin/python scripts/progress_selfplay.py --watch
```

5초마다 동일 화면 갱신. 진행 바, 현재 판·수, 최근20판 속도, 남은 시간과Asia/Seoul 종료 시각, 유효/제외 판수,400회 후보 국면수,가치1/20 선택 시 예상 개수,400/100실제 배분,최근40판 시간 추이를 표시한다. 표준라이브러리만 사용하고 GPU를 사용하지 않는다. 완료된 게임 JSON은 캐시한다. PID 종료 또는180초 이상 갱신 지연 시 ETA를 보류한다. Ctrl+C는 모니터만 종료하며 생성은 계속된다. 대화형 터미널에서는 별도 화면 버퍼와 커서 숨김을 사용하고 종료 시 복원한다. --watch 없이 한 번만 출력, --interval로 갱신 간격 지정.
