# 400회 MCTS 자가대국으로 정책·가치 공동 학습

2026-10-18 사용자 요청으로 추가한 실험. 기존 SL 고정 최종 엔진에서 한 단계 확장해, MCTS로 개선한 대국 정책을 신경망에 다시 학습한다. AlphaGo Zero/KataGo 계열의 탐색 기반 정책 반복 아이디어를 사용하지만 KataGo 전체 구현이나 동일 효율을 주장하지 않는다. 빠른 롤아웃은 추가하지 않는다.

## 최초 파일럿

- 초기 정책: checkpoints/sl_6x96/final.pt.
- 초기 가치: checkpoints/value_own/best.pt (10월 16일 학습한 실제 사용 가치망).
- 두 망은 별도 구조를 유지하고 각각 stem/trunk와 필요한 head를 업데이트한다. 단일 공유 trunk로 합치지 않는다.
- 자가대국 16판. 각 수 정확히 400회, 신경망 추론 배치 32. 양쪽 모두 동일한 고정 생산 모델을 사용한 뒤 대국 묶음이 끝나면 학습한다.
- 각 수 새 트리에서 시작한다. 착수 간 트리를 재사용하지 않아 이전 방문 통계가 400회 예산을 섞지 않는다.
- 탐색 다양성: 루트 prior의 25%를 Dirichlet(alpha=0.03) 잡음으로 대체. 처음 30수는 방문 비례(T=1), 이후 T=0.2로 선택한다. 학습 정책 정답은 선택한 한 수가 아니라 전체 방문 분포다.
- 실제 탐색에 사용한 superko-aware 특징을 착수 전 저장한다. 나중에 기본 규칙으로 재구성하며 특징이 달라지는 문제를 피한다.
- 중국식, 덤 7.5, positional superko, 기권 없음. 두 번 패스 종료. 수순 상한 600수는 Void 처리한다.
- GNU Go level 10, 명령별 30초 타임아웃으로 최종 승패·사석 판정. 상한 종료 또는 판정 실패 판은 두 head 학습에서 모두 제외한다. MCTS 예상 승률을 승패 정답으로 복사하지 않는다.
- 유효한 train/validation 기보가 없으면 실패 상태로 종료하며 라벨을 임의 생성하지 않는다.

## 공동 학습

- 기보 번호 modulo 4 == 3인 4판은 검증 전용, 나머지 최대 12판 학습. 같은 판의 국면이 두 쪽에 섞이지 않는다.
- 정책 정답: 각 수의 362개 행동(패스 포함) root 방문 비율. cross entropy.
- 가치 정답: 종국 GNU Go 승패를 해당 국면의 착수자 관점으로 변환한 +1/-1. MSE.
- 보조 소유권 head도 최종 소유권으로 계속 학습, 손실 가중치 1.5.
- 원 SL 정책을 고정 anchor로 둔 KL 가중치 0.05. 이 파일럿에서 급격한 정책 이탈을 줄이는 선택이며 최적값이라는 근거는 없다.
- 회전·반사 8가지에 대해 특징·정책 분포·소유권 정답을 함께 변환한다.
- 양 망을 같은 배치에서 역전파하고 하나의 SGD optimizer로 업데이트한다. momentum 0.9/Nesterov, 배치 32, 최대 2 epoch 상당(500 업데이트 상한), gradient norm 5 제한.
- 정책 초기 lr 0.0005, 가치 초기 lr 0.001, 각 단계에서 cosine으로 10%까지 감소. 구조나 규모를 키우지 않는 보수적 smoke/pilot 설정이다.
- 정책 체크포인트 내부의 과거 SL value head는 사용하거나 학습하지 않는다. trunk가 바뀌므로 이 옛 value head의 출력은 새 엔진 가치로 해석하면 안 된다. 반드시 쌍으로 저장한 별도 value.pt를 전달한다.

## 대국 평가

기존 SL 정책+value_own과 신규 정책+신규 가치망의 전체 엔진을 비교한다. 양쪽 400회, 배치32, 같은 cpuct/FPU, 평가 중 루트 잡음 및 착수 샘플링 없음.

- 서로 다른 SL 표본 포석 5개(각 8수), 같은 포석에서 흑백을 바꿔 10판.
- 상한/판정 실패는 Void로 별도 집계. 같은 GNU Go로 판정한다.
- 승률·Wilson 95% 구간·실제 방문 수·계산 시간을 저장한다. 10판은 기력 우세를 확정하기에 작다.
- 모델은 브라우저 8765/8766에 자동 적용하지 않는다. 큰 검증에 앞선 파이프라인 확인용이다.

## 실행·진행률·재개

```sh
.venv/bin/python scripts/search_policy_iteration.py --watch
```

실행 또는 재개:

```sh
.venv/bin/python -u scripts/search_policy_iteration.py --visits 400
```

현재 runs/experiments/search_iteration_400_20261018에 대기 프로세스가 등록되어 있다. 기존 가치망 데이터 비교 실험의 파일 잠금이 풀린 뒤에만 GPU 작업을 시작한다. 동일 파일럿 중복 실행은 별도 잠금으로 차단한다.

각 판이 끝날 때 NPZ 및 SGF를 저장한다. 전원 중단 시 완료 기보와 완료 평가 대국은 재사용한다. 짧은 공동 학습 도중 중단되면 그 반복의 생산 모델에서 학습 단계를 다시 시작한다(optimizer 중간 상태 이어하기는 현재 미구현). --iterations를 늘리면 다음 반복에 앞서 학습한 두 망을 생산 모델로 사용하고, 이전 반복의 학습 기보를 재사용한다. 과거 검증 기보는 계속 학습에서 제외한다. 최초 실행은 1반복만 수행한다.

자가대국 단계에서는 최근 완료 기보 5개의 평균 시간으로 남은 시간과 예상 종료 시각을 표시한다. 첫 판이 끝나기 전에는 추정하지 않으며, 후속 학습·평가 시간은 별도다.

## 검증과 한계

- 관련 unit/regression 15개 통과: 실제 400회 방문 합, 패스 포함 soft 정책 정답, 흑백 가치 관점, 상한/계가 실패 제외, 8방향 변환 정합성, 양쪽 trunk 업데이트 및 anchor 보존 등.
- CPU 소형 네트워크로 8개의 2수 테스트 기보(각 수 400회) 저장, 공동 업데이트, 두 체크포인트 재로딩 확인. 이는 실제 기력 검증이 아니다.
- 실제 완료된 319수 기보를 GNU Go level10으로 판정해 유한 점수와 361개 소유권 배열 확인.
- 빈판에 두 번 패스한 비현실적인 기보의 GNU Go 판정은 30초 타임아웃이 발생했다. 타임아웃 판은 라벨 없이 제외하는 경로를 유지하며 임의로 결과를 추정하지 않는다.
- 현재 MCTS는 두 번 패스 후 탐색을 멈추지만 terminal leaf는 신경망 값으로 평가한다. GNU Go는 실제 자가대국 종료 후 라벨 판정에만 쓴다. 탐색 편향과 GNU Go 오류가 남을 수 있다.
- 소수 기보와 2 epoch만으로 강해진다는 보장은 없다. 먼저 실행 안정성·실제 처리 속도·기보 품질을 확인하고 더 큰 데이터와 대국 평가를 결정한다.
