# 프로젝트 결과 정리 (2026-10-13 ~ 2026-10-23)

목표: AlphaGo(2016) 파이프라인(SL 정책망 → RL 정책망 → 가치망 → MCTS)을 Apple M3 Pro 맥북 한 대로
축소 재현해 19줄 아마추어 수준에 도달. 이후 AlphaGo Zero / KataGo 방식(MCTS 자가대국 학습)으로 확장 실험.

## 최종 엔진

| 바둑판 | 구성 | 용도 |
|---|---|---|
| http://localhost:8765 | SL 정책망 + 별도 가치망(`value_own`) + MCTS | 기본 엔진. 사활·형세 판단이 가장 정확 |
| http://localhost:8768 | 1바퀴 공유모델(`search_finetune_20261019`) + MCTS | 평가 1회로 정책·가치를 같이 내서 탐색 약 2배 빠름 |
| http://localhost:8767 | 집 차이 head 공유모델(`scorehead_20261023`) + MCTS | 예상 집 차이 표시(참고용, 대마 사활 국면에서 크게 틀릴 수 있음) |

모든 망은 잔차 6블록 × 96채널(약 100만 파라미터), 입력 34평면(축·활로 등 손 특징 포함).

## 기력 측정 (KataGo 사람 모방 모델, 수당 40회, 프로필당 40판, 우리 엔진 수당 800회)

| 상대 프로필 | SL 정책 + 기존 가치망 + MCTS 800 | 1바퀴 공유모델 + MCTS 800 |
|---|---|---|
| 5급 | 40승 0패 (100%, 95% 91~100%) | – |
| 1급 | 37승 3패 (92%, 95% 80~97%) | – |
| 1단 | 28승 12패 (70%, 95% 55~82%) | 24승 16패 (60%, 95% 45~74%) |
| 3단 | **19승 21패 (48%, 95% 33~63%)** | **19승 21패 (48%, 95% 33~63%)** |

판정: 두 엔진 모두 **KataGo 사람 모방 3단과 대등**하다. 1단은 확실히 이기고(별도 가치망 엔진은 95% 구간 하한 55%),
3단과는 반반이다. 원래 목표(아마추어 수준, 초단 전후)를 넘어 **아마 2~3단 수준**으로 본다.
같은 탐색 횟수에서 공유모델은 1단 상대가 조금 낮지만(60% vs 70%) 구간이 겹쳐 차이를 확정할 수 없다.

KataGo 사람 모방 모델(`b18c384nbt-humanv0`)이 해당 급수의 사람을 흉내 낸 상대이며, 실제 서버 급수와 같지 않다.

## 단계별 결과

| 단계 | 결과 |
|---|---|
| SL 정책망 | KGS + Fox 7~9단 약 8,100만 국면, 6×96. 사람 수 예측 정확도 약 54% |
| RL 정책망 (REINFORCE, 상대 풀, KL 고정) | 3,000회 반복(약 77만 판). SL 상대 약 80% (AlphaGo RL과 같은 수준). 3,600회까지 이어서 해도 52% (정체) |
| 가치망 (AlphaGo 방식 생성 데이터) | 생성 24.8만 판 + RL 기록 + 사람 대국. 생성 테스트 MSE 0.457 |
| MCTS (PUCT, 배치 평가) | 정책망 단독보다 크게 강함. 바둑판 실시간 분석 포함 |
| MCTS 자가대국 1바퀴 (2,261판) | 원래 공유모델 상대 64% (50판) |
| 2바퀴 (3,000판) | 1바퀴 상대 53% (100판) — 같은 400회 탐색 정답을 이미 다 배운 상태 |

## 가치망 개선 시도 (모두 대국 실력 변화 없음)

| 시도 | 가치 MSE | 대국 (400회, 100판) |
|---|---|---|
| 망 키우기 8×128 (처음부터) | 0.630 (기존 0.621) | – |
| RL 생성 데이터 6배 (148.6만 판 추가, 판당 2국면: U번째 수 직후 + 무작위 1) | 거의 같음 (0.456 vs 0.457) | 49% |
| 같은 데이터로 공유모델 학습 | 2바퀴 대비 조금 개선 | 약 49% |
| 가치 정답 = 0.5×승패 + 0.5×MCTS 승률 | 모든 테스트셋에서 조금 개선 | 50% (T5 국면 오판 재발) |
| 집 차이 head 추가 (KataGo 보조 정답) | 집 차이 오차 약 28집, 나머지 같음 | 약 52% (64판에서 중단) |

결론: 이 규모(6×96, 맥 한 대)에서는 데이터·정답을 바꿔도 가치망이 실전 실력을 더 올리지 못했다.
남은 유력 원인은 망 구조(판 전체를 못 보는 깊이, global pooling 없음)와 자가대국 판수(AlphaGo Zero 대비 약 1/1,000).

## 5바퀴 (2026-11-09): 탐색량 2.4배 → 3바퀴 상대 60%

- 자가대국: 3바퀴 모델로 M1 Max에서 20,000판. 학습용 수 12.5%에 1,600회(새 트리, 루트 잡음),
  나머지 수는 200회(트리 재사용), 처음 30수는 방문 비율대로 선택. 판당 학습 국면 약 37개, 가치 정답은 그 절반(약 18개).
- 학습: 3바퀴 모델에서 출발, 5바퀴 데이터만, 2 epoch, lr 0.001 (`pipelines/round5_train_eval.sh`).
  검증 지표는 거의 그대로: 정책 CE 2.343 → 2.339, 가치 MSE 0.701 → 0.703, top1 일치 64.3% → 62.6%.

| 비교 (400회, 100판씩) | 결과 | 95% 구간 |

| 5바퀴 vs 3바퀴 (seed 20261050) | 61승 39패 | 51~70% |
| 5바퀴 vs 3바퀴 (seed 20261060, 재확인) | 59승 41패 | 49~68% |

판정: 5바퀴가 3바퀴보다 강하다(약 +70 Elo). 4바퀴(800회 6.25%, 100회)와 달리 탐색량을 늘린 게 효과.
가치 MSE는 그대로라 향상은 주로 정책 쪽으로 보인다.

가치 정답 관찰: 5바퀴 학습 국면 7,470개에서 1,600회 탐색 루트 Q와 최종 승패의 MSE는 0.683으로
가치망(0.70)보다 낮다. 6바퀴 학습에서 `--search-mix 0.5`(정답 = 0.5×승패 + 0.5×루트 Q)를 적용해 본다.
(`pipelines/round5_searchmix.sh`는 5바퀴 데이터로 같은 비교를 하려다 6바퀴 자가대국을 위해 중단.)
